## 当前阶段的重要学习结论

- 新老客户分别算“邮件−不发”的增量，再比较两个增量；不比较邮件组原始收入就推断谁更适合营销。
- 三个维度的HC3联合Wald检验，H0为该维度两种邮件所有交互差异为0；探索性Holm针对三个维度，与总体两项收入Holm分开。不显著既不证明相等，也不证明存在差异。
- 新客户更高的样本增量只提出下一轮候选假设；是否再做实验由业务价值决定。只研究男装时需新老客户内各设男装/不发四单元，样本量针对增量之差。
- 净收益是收入增量×假设毛利率−每名客户的增量触达成本。置信区间只包含收入抽样不确定性，假设参数未验证，历史结果不直接证明当前业务盈利。
- 技术审计通过不等于个人已经独立实现全部代码或通过全部面试追问。
