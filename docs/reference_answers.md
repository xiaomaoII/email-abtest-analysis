# 参考答案与自查

先做 `learning_path.md` 对应练习，再查看本页。真实数据结果以每次生成的报告为准，本页重点解释方法。

## 第一阶段

业务问题可表述为：对过去一年购买过的客户，两种主题邮件是否比不发邮件带来更多两周收入？要决定下一轮是否继续投入，而不是简单比较两组收入总额。

主指标是总收入除以全部随机分组客户数。对照组保留自然购买的参考。零消费客户也消耗触达资源、属于决策人群，不能移除。`visit`、`conversion` 是实验后结果，先过滤会改变比较对象。

SQL 完整参考在 `sql/01_metrics.sql`。独立验证可用 pandas 的 `groupby(...).agg(...)`，人数应使用 `size`，不能用不说明缺失口径的 `count` 掩盖缺失。

相同字段不一定是相同用户；没有真实 ID，不能凭属性去重。金额高不等于错误，先保留，再通过区间和必要的敏感性分析说明不确定性。

## 第二阶段

SRM：比较三组人数与预期1∶1∶1，发现比例异常后先查随机化、日志或筛选机制。SMD：标准化比较实验前属性均值；类别拆成0/1指标。两者都不能证明全过程无问题。

Welch 收入差的标准误为 sqrt(s_t²/n_t + s_c²/n_c)，自由度按 Welch–Satterthwaite 公式估计。置信区间表述估计过程的不确定性，不能说“真实效应有95%的概率在此次固定区间里”。

两个 p 值的 Holm 手算例子：若为0.01与0.04，升序后分别乘2、1，再取累计最大值，得到0.02与0.04。若为0.03与0.04，校正后为0.06与0.06，两者都不通过0.05阈值。

Bootstrap 小例子可以用实验组 `[0,0,10,20]`、对照组 `[0,0,0,10]`。每轮各抽4人，先求均值再作差。只抽购买者会更换目标量。

“一组显著、另一组不显著”不等于两组差异显著，因为各自的不确定性不同；需要直接检验两组效果的差异。

## 第三阶段

交互检验判断策略效果是否随某个实验前属性变化。联合检验显著只说明存在某些差异，不能定位到所有群体。多次探索会增加发现偶然模式的机会，因此需新样本验证。

如果假设收入增量为0.50美元、毛利率40%，点估计盈亏平衡触达成本是0.20美元。这只是算术演示，不是本项目估计结果。要支持推广，必须再检查收入区间、真实成本和护栏。

样本量近似随 MDE 的平方倒数变化：MDE 减半，所需人数约变为四倍。没有日均合格流量，就不能把人数换算成实际天数；最后一批用户也需要完整14天观察。

面试表达应包含“我用公开数据复盘”“我如何保证口径”“数据支持什么”“还缺什么”。不要把建议写成已经完成的公司业绩。
