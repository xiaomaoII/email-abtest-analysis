# v1.0 — Hillstrom 邮件实验分析学习展示版

首个公开学习展示版本，包含收入增量分析、固定毛利率与成本情景、图表、业务摘要，以及可追溯的指导练习与版本管理记录。

## 主要内容

- 基于2008年Hillstrom随机实验的64,000名客户，比较男装、女装邮件与不发邮件的两周人均收入，分母包含零消费客户。
- 展示收入区间图和完整精度CSV；使用Holm报告主要收入检验、Bonferroni单项97.5% Welch区间报告图表不确定性。
- 包含SRM、SMD、Bootstrap、探索性分群、辅助比例指标、条件净收益及未来样本量规划的学习记录。
- 提供经本人审阅的一页摘要、个人指导练习展示Notebook及参考分析入口。
- 代码和随附项目文档采用MIT许可；数据来源与第三方材料的适用范围单独说明。

## 结果与适用边界

两种邮件均有正向收入增量证据。在毛利率40%、每名分组客户触达成本0.10美元的固定假设下，男装条件净收益区间全正，女装跨零。不能据此确认两邮件直接优胜、已验证的定向人群策略或当前业务实际盈利。

个人练习已有运行及结果核验记录；本次展示整理未重跑分析。G5新克隆与独立环境复现按本人要求跳过，不作该项验收声明。仓库公开状态及关键页面、文件的无登录HTTP访问已核验。
