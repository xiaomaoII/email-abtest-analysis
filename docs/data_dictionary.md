# 数据字典与口径

一行代表一名客户。原始金额为美元。原作者只提供两周累计结果，没有逐日事件表、订单数、性别或真实用户 ID。

| 字段 | 时点与类型 | 含义 | 用途与限制 |
| --- | --- | --- | --- |
| recency | 实验前，1—12整数 | 距最近一次购买的月数 | 不能当作实验天数 |
| history_segment | 实验前，类别 | 过去一年消费金额分档 | 与 history 表达相关信息，不是独立结果 |
| history | 实验前，非负数 | 过去一年消费金额 | 不等于实验前两周消费 |
| mens | 实验前，0/1 | 过去一年是否购买男装 | 不是用户性别 |
| womens | 实验前，0/1 | 过去一年是否购买女装 | 可以与 mens 同为1 |
| zip_code | 实验前，类别 | 城市/郊区/乡村类型 | 不是真实邮政编码；原值 Surburban 在分析层规范拼写 |
| newbie | 实验前，0/1 | 是否为近十二个月的新客户 | 新客户也来自原实验合格客群 |
| channel | 实验前，类别 | 过去一年的购买渠道 | Phone、Web、Multichannel |
| segment | 分组，类别 | No E-Mail、Mens E-Mail、Womens E-Mail | 不过滤或合并三组 |
| visit | 实验后，0/1 | 后续两周是否访问网站 | 实验后变量，不用于预先人群分层 |
| conversion | 实验后，0/1 | 后续两周是否购买 | 是客户购买标记，不是订单数 |
| spend | 实验后，非负数 | 后续两周消费金额 | 零消费必须保留 |
| source_row_id | 项目派生，整数 | 原始 CSV 数据行的顺序编号，从1开始 | 只用于追溯，不能视为真实用户 ID |
| customer_type | 项目派生，类别 | 已有客户 / 近12月新客户 | 根据 newbie 生成 |
| history_band | 项目派生，类别 | ≤100 / 100–350 / >350 美元 | 区间右闭，100 属于第一档，350 属于第二档 |
| recency_band | 项目派生，类别 | 1–3 / 4–6 / 7–12 个月 | 区间右闭，3 属于第一档，6 属于第二档 |

## 指标单位

- 人均收入、收入增量及成本：美元/随机分组客户。
- 访问率、购买率：0—1 的比例；报告按百分比展示。
- 比例的绝对差乘100才是“百分点”；相对提升为 实验均值/对照均值−1，两者不同。
- 相对提升的对照均值为零时不可用，不能填0或无穷大。
- 全部输出表中的空值表示不适用或不可估计；例如辅助指标没有收入检验的 Holm 校正值。

## 核验与追溯

`quality.json` 记录缺失、逻辑一致性、相同属性记录、拼写规范化数量与保留规则。`hillstrom.source.json` 记录实际下载来源、镜像情况、时间和校验值。源文件始终保留原样。
